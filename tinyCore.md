# 🛠️ Налаштування Середовища Розробки та Компіляція Коду для ATtiny412 / ATtiny1624 (megaTinyCore)

## Пролог: Переваги та Недоліки "голих" ATtiny порівняно з Arduino

Коли ви переходите від використання готових плат (як-от Arduino Nano або Uno) до роботи з окремими мікроконтролерами (bare-metal chips), ви отримуєте повний контроль над "залізом", але берете на себе частину інженерної рутини.

#### 🟢 Переваги "голого" ATtiny

* **📏 Екстремальна мініатюрність:** ATtiny412 (8 пінів) або ATtiny1624 (14 пінів) займають у десятки разів менше місця, ніж будь-яка Arduino. Це ідеально для створення власних друкованих плат (PCB) та розміщення пристроїв у дуже компактних 3D-друкованих чи вирізаних лазером корпусах.
* **🔋 Справжня енергоефективність (Deep Sleep):** На готових платах Arduino завжди є "паразити": світлодіоди живлення, USB-міст (CH340/FT232) та лінійні стабілізатори (LDO). Вони постійно споживають струм. Голий чип у режимі сну (Power-Down) споживає мікроампери (або навіть наноампери), що дозволяє пристрою працювати від однієї батарейки-монетки місяцями чи роками.
* **💰 Вартість:** Окремий мікроконтролер коштує від кількох десятків центів до долара, тоді як готова плата обійдеться в $4-20. Це суттєво здешевлює створення кількох однакових пристроїв.
* **⚙️ Сучасна архітектура (tinyAVR 0/1/2-series):** Ці чипи на покоління новіші за ATmega328P (серце Arduino Uno). Вони мають Event System (апаратна взаємодія периферії без участі процесора), Configurable Custom Logic (вбудовані логічні вентилі) та кращі АЦП/ЦАП.
* **🔌 Гнучкість дизайну:** Ви самі вирішуєте, де і які компоненти будуть стояти. Немає жорсткої прив'язки до пінів (наприклад, вам не заважатиме вбудований LED на 13-му піні).

#### 🔴 Недоліки та Виклики

* **🛠 Складність макетування (Breadboarding):** Сучасні ATtiny майже не випускаються у зручних для макетних плат DIP-корпусах. ATtiny1624 постачається у SMD-корпусах (SOIC або VQFN). Для прототипування доведеться припаювати їх на спеціальні плати-перехідники (breakout boards), або займатися deadbugging (припаюванням дротів до пінів мікроконтролера)
* **🔌 Відсутність "Plug-and-Play" USB:** Ви не можете просто вставити кабель Type-C або Micro-USB і завантажити код. Вам завжди потрібен зовнішній USB-UART адаптер, резистор та налаштований SerialUPDI.
* **⚡ Апаратна обв'язка:** Ардуїно пробачає нестабільне живлення. З голим чипом ви самі відповідаєте за фільтрацію перешкод. Вам обов'язково потрібно ставити розв'язувальні (decoupling) керамічні конденсатори (зазвичай 100 нФ) максимально близько до пінів VDD та GND чипа.
* **📚 Крутіша крива навчання:** Доведеться частіше відкривати даташити, розумітися на мультиплексуванні пінів та обмеженнях.


## 🔍 Ідентифікація Обладнання та Підключення

Ваша плата: Голий чип ATtiny412 або ATtiny1624 (мікроконтролери сучасного покоління tinyAVR) або саморобна макетна плата на їх базі.

> Ці чипи кардинально відрізняються від старих класичних AVR (як ATmega328P або ATtiny85). Вони використовують сучасний однопровідний інтерфейс програмування UPDI замість 6-пінового ISP.

| ATtiny412 (8-pin) | ATtiny1624 (14-pin) |
| --- | --- |
|  |  |

* **Підключення:** Використовуйте звичайний USB-UART конвертер (наприклад, CH340 або CP2102) для прошивки через метод **SerialUPDI**.
* **⚠️⚠️⚠️Важливо⚠️⚠️⚠️:** Для створення SerialUPDI програматора потрібно з'єднати контакти **RX** та **TX** вашого конвертера через резистор номіналом 4.7 кОм (або 1 кОм), і цей єдиний спільний провід підключити до піна **UPDI** (PA0) на мікроконтролері. Переконайтеся, що рівні напруги конвертера (5В або 3.3В) збігаються з робочою напругою чипа.

## 💡 Теоретичні Основи

Перш ніж зануритися в процес встановлення, важливо зрозуміти роль ключових інструментів, які ми будемо використовувати.

### 📦 Що таке megaTinyCore?

megaTinyCore — це неофіційне ядро (core) для середовища розробки, створене розробником SpenceKonde. Воно містить усі необхідні бібліотеки, макроси, визначення регістрів та компілятор (avr-gcc) для новітніх чипів tinyAVR (серій 0, 1 та 2). Без нього стандартні інструменти просто не знатимуть, як правильно зібрати код під архітектуру ATtiny1624.

### ❓ Чому SerialUPDI, а не класичні програматори?

UPDI (Unified Program and Debug Interface) — це пропрієтарний протокол Microchip для програмування нових AVR по одному дроту. Замість купівлі дорогого офіційного програматора (наприклад, Atmel ICE), спільнота розробила програмний метод `pyupdi`. Він дозволяє звичайному дешевому USB-UART конвертеру імітувати протокол UPDI, що робить розробку максимально доступною.

### 🌳 Навіщо потрібен PlatformIO у VS Code?

Хоча megaTinyCore можна легко встановити в класичну Arduino IDE, для глибокої розробки (низькорівнева робота з портами, перериваннями та C/C++) набагато зручніше використовувати розширення PlatformIO для Visual Studio Code. Воно автоматично завантажує потрібний Toolchain, дозволяє легко конфігурувати ф'юзи та компілює код швидше і прозоріше.

### ⚙️ Як працює процес компіляції та завантаження?

Процес перетворення вашого коду на функціональну програму на чипі складається з наступних кроків:

1. **Вихідний Код (Source Code):** Ви пишете код на C/C++ у VS Code.
2. **Компіляція (Toolchain):** PlatformIO викликає компілятор `avr-gcc`, який перетворює код на оптимізований бінарний файл (`.hex`), розрахований під конкретний об'єм флеш-пам'яті (наприклад, 16 КБ для ATtiny1624).
3. **Прошивка (Flash):** Інструмент завантаження (зазвичай `avrdude` з інтеграцією pyupdi) відправляє цей файл через ваш USB-UART конвертер прямо в пам'ять чипа по єдиному проводу UPDI.

## 💻 Покрокове Встановлення Середовища Розробки

### Крок 1: Встановлення Базового ПЗ

* **Редактор Коду:** Встановіть [Visual Studio Code (VS Code)](https://code.visualstudio.com/)
* **Середовище для мікроконтролерів:** У VS Code відкрийте вкладку Extensions (Розширення) і встановіть **PlatformIO IDE**.
* **Мова:** Разом із PlatformIO автоматично встановиться розширення C/C++.

```
Рекомендація: Після встановлення PlatformIO дочекайтеся закінчення фонових процесів (внизу праворуч буде йти інсталяція системних файлів) і обов'язково перезапустіть VS Code.

```

### Крок 2: Налаштування Робочої Директорії

Створіть папку для проєктів, де НЕ БУДЕ кирилиці⚠️ або пробілів.

**Приклад:** `D:/code/attiny-projects`

### Крок 3: Створення Проєкту

1. Відкрийте вкладку PlatformIO (іконка голови мурахи зліва на панелі) і натисніть **PIO Home -> Open**.
2. Натисніть **New Project**.
3. Введіть назву проєкту.
4. У полі **Board** почніть вводити та оберіть `ATtiny1624` (або `ATtiny412`).
5. У полі **Framework** оберіть `Arduino` (це автоматично підтягне megaTinyCore під капотом).
6. Натисніть **Finish** (перше створення проєкту займе кілька хвилин, оскільки завантажуватимуться всі необхідні компілятори).

### Крок 4: Налаштування platformio.ini

Відкрийте файл `platformio.ini` у вашому проєкті та додайте налаштування для програматора SerialUPDI. Файл має виглядати приблизно так:

```ini
[env:ATtiny1624]
platform = atmelmegaavr
board = ATtiny1624
framework = arduino

; Налаштування частоти (наприклад, 20 MHz)
board_build.f_cpu = 20000000L

; Вказуємо програматор SerialUPDI
upload_protocol = serialupdi
; Вкажіть ваш COM-порт (замініть на актуальний, наприклад COM3 або /dev/ttyUSB0)
upload_port = COMxx
upload_speed = 115200

```

### Крок 5: Перезапуск та Перевірка

1. **Перезапуск:** Збережіть файл `platformio.ini`. PlatformIO автоматично підвантажить потрібні скрипти для UPDI.
2. **Перевірка:** Відкрийте файл `src/main.cpp` та напишіть базовий код (наприклад, мигання світлодіодом або налаштування пінів).

## 🚀 Компіляція та Прошивка Коду

🔨 Компіляція (Збірка)

У нижній синій панелі VS Code натисніть іконку **✓ (Build)**.
PlatformIO автоматично скомпілює ваш код. Якщо помилок немає, ви побачите напис `[SUCCESS]`.

💾 Завантаження (Прошивка)

Переконайтеся, що ваш USB-UART конвертер підключений до чипа (GND до GND, VDD до VDD, з'єднані RX і TX через резистор йдуть до піна UPDI).
Натисніть іконку **➔ (Upload)** у нижній панелі.

🕹️ Вхід у Режим Прошивки (Burning Mode)

На відміну від багатьох інших чипів, **тут нічого натискати не треба!**

* Протокол UPDI працює завжди, поки на чип подається стабільне живлення і пін UPDI апаратно доступний.
* Програматор сам ініціює безпечне скидання (Reset) чипа через лінію UPDI та автоматично заливає прошивку.

### Нотатка

Документація до megaTinyCore написана одним геніальним ентузіастом (SpenceKonde). Вона просто величезна, надзвичайно детальна, але місцями може здатися новачку дещо хаотичною.

Головне правило при роботі з цими чипами: **ніколи не змінюйте конфігурацію ф'юзів так, щоб перетворити пін UPDI (PA0) на звичайний GPIO або класичний RESET**. Якщо ви це зробите, чип більше не зможе приймати прошивки через SerialUPDI, і ви "оцеглите" його. Для відновлення знадобиться спеціальний високовольтний програматор (12V High-Voltage UPDI).

Також пам'ятайте, що мікроконтролер може видавати лише невеликий струм (до 20-40 мА на пін). Для підключення потужнішого навантаження завжди використовуйте логічні N-канальні MOSFET транзистори (наприклад, IRLZ44N).
